# یارا | طرح کلیک‌پذیر سایت اجاره وسایل

صفحه شروع سایت `index.html` است. بقیه صفحه‌ها از داخل همین صفحه‌ها به هم لینک شده‌اند.

## انتشار روی GitHub Pages

1. در GitHub یک مخزن (repository) جدید بساز، مثلاً `yara`.
2. همه فایل‌های این پوشه را (نه خود پوشه را) داخل مخزن آپلود کن، طوری که `index.html` در ریشه مخزن باشد.
   - در صفحه مخزن: **Add file → Upload files**، فایل‌ها را بکش و **Commit changes** را بزن.
   - فایل `.nojekyll` را هم آپلود کن (اگر در فهرست فایل‌ها پنهان بود، از زیپ استخراج‌شده انتخابش کن).
3. به **Settings → Pages** برو.
4. در بخش **Build and deployment**، گزینه **Deploy from a branch** را بگذار، شاخه **main** و پوشه **/ (root)** را انتخاب کن و **Save** را بزن.
5. بعد از یکی دو دقیقه، سایت در این آدرس بالا می‌آید:
   `https://USERNAME.github.io/REPO/`
   (به جای `USERNAME` نام کاربری و به جای `REPO` نام مخزن).

اگر مخزن را با نام `USERNAME.github.io` بسازی، آدرس سایت فقط `https://USERNAME.github.io/` می‌شود.

## فایل‌ها

- `index.html` صفحه اول سایت (موبایل)
- `pages.html` فهرست همه صفحه‌های طراحی‌شده
- `404.html` صفحه خطا (GitHub Pages خودش نشانش می‌دهد)
- بقیه صفحه‌ها با شماره (`02-search.html` تا `17-home-user.html`)

## نکته‌ها

- نام همه فایل‌ها با حروف کوچک و بدون فاصله است، چون GitHub Pages به حروف بزرگ و کوچک حساس است.
- آیکون‌ها داخل خود فایل‌ها هستند. فقط فونت وزیرمتن از اینترنت لود می‌شود و اگر لود نشود، فونت پیش‌فرض دستگاه استفاده می‌شود.
- این‌ها نمونه طراحی هستند و به سرور وصل نیستند.

## اجرای محلی با XAMPP و phpMyAdmin (محصولات و عکس‌ها از دیتابیس)

محصولات، عکس‌ها و لیست صفحه‌ی اصلی کاربر حالا از دیتابیس MySQL خوانده می‌شوند، پس سایت باید از طریق Apache اجرا شود (نه با دابل‌کلیک روی فایل).

1. XAMPP را باز کن و **Apache** و **MySQL** را Start کن.
2. کل پوشه‌ی پروژه را با نام `yara` کپی کن داخل `C:\xampp\htdocs\` (یعنی `C:\xampp\htdocs\yara\index.html` وجود داشته باشد).
3. برو به `http://localhost/phpmyadmin` ← تب **Import** ← فایل `database/yara.sql` را انتخاب کن ← **Import**.
   این کار دیتابیس `yara` را با جدول‌های `products`، `product_images` و `home_feed` می‌سازد.
4. تست اتصال: `http://localhost/yara/api/check.php` باید تعداد محصولات و عکس‌ها را نشان بدهد.
5. سایت: `http://localhost/yara/`

اگر رمز root در MySQL را عوض کرده‌ای، فایل `api/config.php` را ویرایش کن.

### ویرایش از phpMyAdmin
- **تغییر قیمت و مشخصات:** دیتابیس `yara` ← جدول `products` ← Edit روی ردیف.
- **محصول جدید:** در `products` یک ردیف Insert کن.
- **عکس جدید:** جدول `product_images` ← Insert ← `product_id` را برابر `id` محصول بگذار و در ستون `image` با دکمه‌ی انتخاب فایل، عکس را آپلود کن (`mime` مثلاً `image/jpeg`).
- ترتیب نمایش با ستون `sort_order` است. `is_active=0` یعنی محصول نمایش داده نشود.

### نکته‌ی انتشار
نسخه‌ی PHP روی GitHub Pages کار نمی‌کند، چون آن‌جا فقط فایل ثابت اجرا می‌شود. برای انتشار آنلاین به هاستی نیاز داری که PHP و MySQL داشته باشد.
